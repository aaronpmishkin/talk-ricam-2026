# SIAM OP26 Talk 

This repository contains the slides and LaTeX source for the talk "Global
Optimization of Deep Relu Networks Using Convex Reformulations" which I
gave at SIAM OP26. 

This talk was part of the minisymposium on 
[Global Optimization for Neural
Networks](https://meetings.siam.org/sess/dsp_programsess.cfm?SESSIONCODE=87538)
which I co-organized with Mert Pilanci and Sungyoon Kim.
